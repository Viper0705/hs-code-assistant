Help & feedback

Support

HS Code Assistant is maintained by Marco Passarini.

Report a problem or suggest an improvement

Use the project’s GitHub Issues page to report technical problems or suggest improvements. A GitHub account is required to open an issue.

GitHub Issues are public.

Do not post confidential product specifications, customs declarations, personal information, credentials or internal company documents. Use an anonymised example.

Private contact

For questions that should not be posted publicly, contact marco@viper07.it. Start with a brief description; do not attach sensitive documents.

Useful information to include

  • Which feature you were using and what you expected.
  • A short, anonymised description of the issue.
  • The date and the platform you were using.

Support does not provide a binding classification decision. No response time is guaranteed.
